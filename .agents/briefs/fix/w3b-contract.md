# 3b-1 – agent `contract` (chạy một mình, xong mới tới agent khác)
Sở hữu: `proto/`, `gen/go`, `pkg/common/`, `docs/contracts.md`, `docker-compose.yml`, `.env.example`, hằng `CANONICAL_PRIMARY_SUBJECTS` trong `services/payment/src/workers.rs` (chỉ mảng đó), `SERVICE_METHODS` trong `services/payment/src/auth.rs` nếu cần. Theo `w3b-plan.md` §2 (E1–E21); số trường lấy ở `w3b-design-a4.md` §2 và `w3b-design-a5.md` §2, kiểm lại với proto thật.
1. Proto, chỉ thêm, `buf breaking` sạch so với HEAD: product (review, từ cấm, `rating_avg_x100`, `review_count`, `flagged_keywords`, `is_prohibited`, stub ngừng bán; KHÔNG `CheckBannedContent`), cart (E3), shipping (`QUEUED`, `cod_supported`, `fallback_weight_item_qty`, `queued/job_id`; KHÔNG `AdminTestCarrier.api_token`), user (`RequestPhoneOTP`, `VerifyPhoneOTP`), order (`shipment_job_status`, `queued`…), payment (`ImportCodReconciliation`, `ListReconciliationRuns`, trường hàng đợi). `make proto`; mọi module Go và `payment` build được (handler chưa có thì embed Unimplemented, không viết thân giả).
2. `pkg/common/auth`: phân loại mọi RPC mới; `CalculateFee` → public; test phân loại xanh. `pkg/common/jetstream`: thêm `review.>` ở Go và Rust.
3. Compose/.env.example: env của E17–E19, `ORDER_GRPC_ADDR`/`USER_GRPC_ADDR` cho `product` (không `depends_on` vòng). Không khoá thật.
4. `docs/contracts.md`: REST, RPC, event (`review.created`, `user.phone_otp_requested`, phần mở rộng `shipment.updated`/`order.delivered`), mã lỗi, env, hành vi E1–E21; sửa chỗ cũ mâu thuẫn (kể cả `from_time`/`to_time` audit chưa ghi).
Kiểm: `make lint`, `make test`, `docker compose config -q`; mã thoát thật.
