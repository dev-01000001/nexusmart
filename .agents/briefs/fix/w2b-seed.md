# Đợt 2b – agent `seed` (sở hữu `tools/seed/**`, `tools/loadgen/**` (mới nếu cần))
Theo `w2b-plan.md` §5: PRM-D1 (suất ≤ tồn), CAT-D3, đơn mẫu ở nhiều trạng thái (đặt, giao, hoàn tất, huỷ, trả hàng) idempotent bằng API thật (không ghi DB), chương trình giảm giá mẫu, lịch phí mẫu; script sinh N sản phẩm (mặc định 20.000, tối đa 50.000) tách khỏi `make seed`, có tiến độ, tiếp tục được, dọn được, tốc độ ghi qua API hoặc COPY vào DB dev (nêu rõ, chỉ project compose local, từ chối chạy khi DATABASE_URL không phải localhost). Chạy sau khi các agent khác xong (phụ thuộc API): chuẩn bị trước, kiểm ở stack audit.
