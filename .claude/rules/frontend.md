# Quy tắc Frontend (`web/`)

- **Hệ thống UI, CSS toàn cục & token `--ui-*` (ADR-0011)**: toàn bộ `web/` dùng **shadcn/ui** (`web/src/components/ui/`, 35 primitive) + pattern ứng dụng (`web/src/components/app/`, 15 component + 3 helper) trên **Tailwind CSS v4** với **preflight bật toàn cục** (`@import "tailwindcss/preflight.css" layer(base);` trong `web/src/styles/ui.css`, nạp ở `web/src/app/layout.tsx`). Toàn bộ màu, bo góc, bóng và font đi qua `--ui-*` + `@theme inline` (không hard-code mã hex rời). Phần ứng dụng dùng 3 bậc bóng nhẹ (`shadow-card`, `shadow-button`, `shadow-overlay`) và font **Inter** (`tabular-nums` cho số liệu/tiền VND); site gian hàng giữ bề mặt phẳng (chỉ overlay có bóng), hỗ trợ 8 mẫu (2 mẫu tối qua `[data-site-theme-mode="dark"]`) và 5 font thật (`resolveSiteUiFontStack`). Ngoại lệ duy nhất: trang chủ `/` (`PlatformHome` và nhánh `data-home="true"` của `PlatformHeader`) dùng gradient, quầng sáng `radial-gradient`, `mask-image`, bóng và bộ biến `--home-*` trong `web/src/features/platform/home/home-tokens.css` (scope `[data-platform-public="true"]` gắn ở `web/src/app/(shop)/(public)/layout.tsx`) cùng `home-keyframes.css`.
- **PostCSS & phụ thuộc UI đã duyệt**: `web/postcss.config.mjs` chỉ khai `"@tailwindcss/postcss": { optimize: false }` (tránh Lightning CSS ép alpha sang hex 8-bit làm lệch gradient trang chủ; Tailwind v4 vẫn phát tiền tố `-webkit-` và Next.js vẫn minify CSS ở production). Chỉ dùng 10 gói UI runtime đã duyệt trong ADR-0011 (`tailwindcss`, `@tailwindcss/postcss`, `tw-animate-css`, `class-variance-authority`, `clsx`, `tailwind-merge`, `radix-ui`, `lucide-react`, `cmdk`, `sonner`); ưu tiên tái sử dụng component sẵn có trong `web/src/components/{ui,app}/` và không khai biến ở `:root` ngoài tiền tố `--ui-*`.
- **Component tương tác phức tạp & `UiScope`**: `Dialog`, `AlertDialog`, `Sheet`, `DropdownMenu`, `Popover`, `Select`, `Tooltip`, `Command` dùng primitive Radix qua `web/src/components/ui/` nối `usePortalContainer()` từ `UiScope` (`web/src/components/ui/ui-scope.tsx`) để overlay thừa kế `--ui-*` và `[data-site-theme-mode="dark"]` trên site tối; không còn CSS reset bám `data-ui` và không tự dựng modal/combobox thủ công.
- **Import từng file & ngân sách JS trên site gian hàng**: trong `web/src/app/(site)/**` và `web/src/features/{site,search,commerce,account,chat,assistant}/**`, luôn import thẳng từng file (không qua barrel `@/components/app` hay `@/features/site`) và nạp lazy overlay nặng bằng `next/dynamic` để giữ First Load JS trang chủ site và PDP ≤ 296 kB.
- **Kiểm tra trực quan và gate trước khi báo xong**:
  - Màn hình mới hoặc thay đổi bố cục phải đối chiếu skill `design-system` (`.claude/skills/design-system/SKILL.md`), chạy kiểm luồng/trạng thái (`tests/ui-flows/run.mjs`, `tests/ui-flows/states.mjs`) và chụp Playwright ở 3 khổ `390px`, `768px`, `1440px` (`.agents/tools/ui-shots.mjs`, `.agents/tools/scroll-shots.mjs`, `.agents/tools/ui-diff.sh`).
  - Chạy xanh toàn bộ cổng tĩnh trong `web/`: `npm run lint`, `npm run format:check`, `npm run test:unit`, `npm run check:data`, `npm run build` (hoàn nguyên `web/tsconfig.json` nếu build với `NEXT_DIST_DIR`).
- **Ngôn ngữ cho người mua**: mọi văn bản hiển thị trong `web/src/app/(shop)/`, `web/src/app/(site)/`, `web/src/components/`, `web/src/features/{account,assistant,chat,checkout,commerce,platform,product,search,site}/` phải viết bằng tiếng Việt tự nhiên cho người mua, không dùng thuật ngữ kỹ thuật nội bộ (JWT, HMAC, Saga, Redis Lua, sandbox, sổ cái ghi kép, optimistic locking).
